# Pallavi Chendake — Portfolio Site

This is a single-page portfolio website built from the provided resume and images.

## Contents
- `index.html` — main site
- `styles.css` — styling
- `script.js` — small JS for interactivity
- `assets/` — profile image (`profile.jpg`), achievement image, placeholders, and `PallaviChendake_resume.pdf`

## To run locally
1. Unzip the project.
2. Open `index.html` in your browser.

## Deploy to GitHub Pages
1. Create a new GitHub repository (e.g. `pallavi-portfolio`).
2. Commit and push all files to the repository.
3. In the repo Settings → Pages (or in GitHub Pages section), choose `main` branch and `/ (root)` folder then Save.
4. After a few minutes, your site will be live at `https://<your-username>.github.io/<repository-name>/`.

Notes:
- The `Download Resume` button links to `assets/PallaviChendake_resume.pdf`. Keep the `assets` folder in root of repo.
- Replace placeholder images in `assets/` with real certificate photos later; keep file names or update `index.html`.
